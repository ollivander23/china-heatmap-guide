# 热力地图工坊：把你的 Excel 数据，变成一张动态地图

**免费 · 免注册 · 数据不上传服务器**

👉 直接打开：**[heatmap.mavi.help](https://heatmap.mavi.help/)**

表格里只要有「一列地名 + 一列数值」，导入、调样式、导出，三步就能拿到一张能直接放进周报、PPT 和汇报文档里的中国行政区划热力地图。

> 这类图严格来说叫 **choropleth map**（分级填色图）——按行政区边界整块填色，颜色深浅代表该区域的数值；和密度型的 heatmap（人流热力、点击热图那种没有边界的连续渐变）不是同一种图。中文里两者常被统称为「热力图」，这里沿用了大家更熟悉的说法。
>

## 它解决的是一个很具体的麻烦

想给一组数据配张地图，这件事本来不该花一晚上。但现有的路子往往卡在几件小事上：在线工具要注册登录、免费版导出带大水印、区县一级要付费、图片底下还有一圈白边塞不进 PPT。

所以做了这个工具：打开网页，把表格拖进去，挑个配色，导出透明背景的高清图。不登录、不收费、不限次数。你的数据也不会被传到任何服务器上——解析、上色、导出，全在你自己浏览器里完成。

## 三步出图

不需要模板，也不用改公式。

**① 导入数据** — 支持 `.xlsx` / `.xls` / `.csv` / `.json`，也可以直接从 Excel 里复制两列粘贴过来。想先看看效果，主页上还有几份现成的样例数据可以直接加载。

**② 调样式** — 在右侧面板切换配色主题、调整色标分级、加标注和排行榜，地图实时跟着变。

**③ 导出 PNG / SVG** — 支持 1x / 2x / 3x 多倍率、透明背景，直接拖进 PPT 不会有白底；需要放大印刷就用 SVG 矢量图。

## 它能做什么

### 省 / 市 / 区县三级，逐级下钻

按 2026 年行政区划，覆盖全国 34 个省级行政区、388 个地级市、2897 个县级行政区。从全国看下去，点进某个省，再点进某个市，同一份数据可以换着角度看。也支持「全国 + 区县级」「某个省 + 区县级」这类交叉视角——想看多细，由你决定，不必先换一张表。

### 地图和排行榜同屏联动

热力地图负责看空间分布，柱状排行榜负责看谁高谁低。两张图可以一键摆到画面的上下左右四个角，缩放、全屏都不用另外排版。汇报时最常被问的那两个问题——「哪儿高」和「谁第一」——一张图就答完了。

### 导入后自动推荐合适的地图

表格丢进来，工具会先告诉你：一共解析了多少行、匹配上多少、还有多少没对上，然后推荐最适合的那张底图（比如你给的是 300 多个地级市，它就会建议用「全国-市」）。不用自己猜该选哪一层。

### 地名不用写成教科书格式

「广东省」和「广东」、「北京市」和「北京」都能识别；克州、巴州、大理州这类自治州简称也内置了对应关系。少一个「省」字、多个「市」字，都不至于让整张图空着。

### 排版细节可以一直调到满意

多套配色主题、起止颜色自定义、分段或连续色标、色标位置和朝向、标题文字、地图上的名称与数值标注、自定义背景色。还支持在地图上打标记点——给门店、项目地址、重点区域单独标一个点。

### 能分享，也能嵌进别人的页面

点「分享」会生成一个短链接和二维码，对方在手机或电脑浏览器里打开，看到的就是同一张图，不用装软件。链接长期有效，还提供一段嵌入代码，可以直接贴进支持 HTML 的文档或博客里，保留完整的交互。

## 导入前，表格整理成这样就行

| 区域 | GDP（亿元） |
| --- | --- |
| 广东省 | 135673 |
| 江苏省 | 128222 |
| 山东省 | 92069 |

三条规则，记住就够了：

1. **两列就够，多列也行。** 一列写行政区名称（省 / 市 / 区县），其余列写数值，表头可写可不写。表里有多列指标时，导入后可以切换用哪一列上色。
2. **地名按平时的习惯写。** 全称、简称都行，一行只写一个层级的地名最稳妥（别写成「广东省深圳市」这种组合）。
3. **数值只留数字。** 把「亿元」「%」和千分位逗号去掉，否则这一列会被当成文本，颜色上不去。单位写在图表标题里就好。

更细的数据准备、导入失败排查、导出参数，看 **[使用指南](docs/使用指南.md)**。

## 和 Excel 自带的「地图」图表比

Excel 也能插地图，但在区县粒度、排行榜联动和导出自由度上差别不小：

| 对比项 | Excel 地图图表 | 热力地图工坊 |
| --- | --- | --- |
| 区域粒度 | 依赖在线地理服务，区县支持有限 | 省 / 市 / 区县三级，可逐级下钻 |
| 排行榜联动 | 需要另外建图表并手动排版 | 地图与柱状图同屏联动，一键四角布局 |
| 透明背景导出 | 不支持 | PNG 透明背景与 SVG 矢量图 |
| 数据去向 | 部分版本需要上传到云端 | 浏览器本地渲染，不上传服务器 |
| 使用成本 | 需要 Office 365 订阅 | 免费，免注册 |

## 常见问题

**需要注册登录吗？收费吗？**
都不需要。打开网页导入数据就能出图，没有额度限制，也不强制登录。

**我的数据会被上传到服务器吗？**
不会。数据解析、地图渲染、图片导出全部在你的浏览器本地完成，工具没有后台数据库，也没有把你的表格存到任何地方。

**为什么有些行是灰色的、没有上色？**
灰色表示这一行的地名没对上行政区划库。常见原因是一行写了多级组合名（如「广东省深圳市」）、有错别字，或者用了没收录的俗称。一行只写一个层级的地名最稳妥，改完立刻重新上色。

**某个区域在地图上找不到怎么办？**
有两类地名本来就不在底图里：一是经济功能区，比如大亚湾区、江北新区、西咸新区，它们跨在几个行政区之上，没有独立边界；二是已经撤销或改名的旧地名，比如新津县、莱芜市、巢湖市。做法是在编辑表格里给它找个「新户口」——功能区的数据合并到它所在的区，旧地名改成现在的名字。

**一张表里同时有省和市的数据会怎样？**
工具照样能出图，并会提示数据包含多个层级。这时可以逐级下钻查看下级数据。想要图面干净，建议把数据统一到同一层级。

**能画到区县一级吗？**
可以，覆盖全国的地级市与区县，也支持「全国 + 区县级」「某个市 + 区县」这类交叉视角，逐级下钻即可。

**导出的图片有水印吗？**
导出时按默认习惯会带审图号水印，也可以在导出面板里选择去掉。

**手机能用吗？**
分享出去的页面在手机上能正常看。制作工作台里有数据表格和多面板设置，屏幕太窄会难用，建议在电脑上做。

## 关于底图与合规

底图与行政区划边界均取自**天地图**，审图号 **GS(2026)4921号**（2026 年 10 月版本）。按天地图的说明，该数据用于地图可视化展示；正式出版、公文报送或对外发布前，请以天地图当前公示的审图号与标准地图再核验一次。

底图按国家行政区划绘制，包含南海诸岛等必要图幅。这也是为什么某些「网上看着有、地图上没有」的功能区或旧地名无法直接上色——它们本身没有独立边界。
