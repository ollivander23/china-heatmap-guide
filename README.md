# 热力地图工坊：把你的 Excel 数据，变成一张动态地图

**免注册 · 数据只在你的浏览器里处理** ｜ 👉 **[heatmap.mavi.help](https://heatmap.mavi.help/)**

> 这类图严格来说叫 **choropleth map**（分级填色图）——按行政区边界整块填色，颜色深浅代表该区域的数值；和密度型的 heatmap（人流热力、点击热图那种没有边界的连续渐变）不是同一种图。中文里两者常被统称为「热力图」，这里沿用了大家更熟悉的说法。

## 一眼看懂

### 它是什么

小而美的 Excel 数据地图工坊：导入两列数据，生成一张可下钻、可与柱状图联动、能直接放进汇报的中国行政区划地图。

### 解决什么

写周报、做经营分析、发公众号，经常卡在同一步：手里有一张「各省 GDP / 各市销量 / 各区县门店数」的表，数字看得累，想要一张地图还得去研究 GIS 软件。这个工具只要求两列数据：一列行政区名称、一列数值。导入后自动匹配省 / 市 / 区县三级行政区划并上色，不用懂坐标、不用装插件。

### 适合谁

经常做周报、区域对比、业绩复盘的运营；学术与科研；政务与公共事务；自媒体作者。

### 和同类比

1. **数据不出你的电脑** —— 表格在浏览器里读、算、画，关掉页面就没了，服务器上没有你的表
2. **底图合规** —— 天地图标准底图，审图号 GS(2026)4921号，按 2026 年最新行政区划绘制
3. **任意区域 × 任意粒度** —— 打破单一层级限制，想看多细由你决定
4. **柱状图联动** —— 可与地图同屏，也可切成全屏柱状图动画
5. **智能推荐地图** —— 导入后自动判断该用哪一级底图
6. **无账号系统** —— 打开就用，没有登录弹窗

## 数据不出这台电脑

门店销量、区域业绩、未发布的季度数据，表里通常带着客户名、地址、金额，这类表不该上传。

表格在浏览器里读、在浏览器里算、在浏览器里画成图，关掉页面，数据就没了。

## 和通用 AI 工具比

AI 能快速给出一张示意图，也能直接生成 ECharts 中国地图代码、自动引入 GeoJSON、配好 series 和 tooltip。但它解决的是「图能不能画出来」，而不是「这张地图能不能直接拿去汇报」。

| 对比项 | 热力地图工坊 | 通用 AI 工具 |
| --- | --- | --- |
| 数据接入 | 直接导入整份 Excel / CSV / JSON | 需粘贴或上传对话，长表易截断、需反复校对 |
| 行政区匹配 | 内置省 / 市 / 区县名称库，自动匹配 | 依赖模型生成，别名、旧地名、多级混写仍需人工核对 |
| 底图合规 | 统一底图，页面与导出图均标注来源和审图号 | 生成图片通常不带审图号；生成代码则取决于所用底图，需自行核验 |
| 数据隐私 | 浏览器本地处理，不上传 | 数据可能进入第三方服务，取决于服务商策略 |
| 结果稳定性 | 同一份数据输出一致，可复现 | 提示词或模型版本变化后输出可能不同 |
| 适合场景 | 周报、经营分析、区域对比、批量出图 | 原型探索、一次性配图、自定义可视化开发 |

## 和 Excel 自带的「地图」图表比

Excel 也能插地图，但在区县粒度、排行榜联动和导出自由度上差别不小：

| 对比项 | Excel 地图图表 | 热力地图工坊 |
| --- | --- | --- |
| 区域粒度 | 依赖在线地理服务，区县支持有限 | 省 / 市 / 区县三级，可逐级下钻 |
| 排行榜联动 | 需要另外建图表并手动排版 | 地图与柱状图同屏联动，一键四角布局 |
| 透明背景导出 | 不支持 | PNG 透明背景与 SVG 矢量图 |
| 数据去向 | 部分版本需要上传到云端 | 浏览器本地渲染，不上传服务器 |
| 使用成本 | 需要 Office 365 订阅 | 免注册，开箱即用 |

## 关于底图与合规

底图与行政区划边界均取自**天地图**，审图号 **GS(2026)4921号**（2026 年 10 月版本）。按天地图的说明，该数据用于地图可视化展示；正式出版、公文报送或对外发布前，请以天地图当前公示的审图号与标准地图再核验一次。

底图按国家行政区划绘制，包含南海诸岛等必要图幅。这也是为什么某些「网上看着有、地图上没有」的功能区或旧地名无法直接上色——它们本身没有独立边界。
