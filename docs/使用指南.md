# 使用指南

题目里的「三步出图」是真的三步，但第一次做的时候，数据整理往往比点鼠标费时间。下面把容易卡住的地方一次说完。

---

## 0. 一分钟上手

1. 打开 <https://heatmap.mavi.help/>
2. 主页下方有现成样例数据，先点一份「加载样例」，看看成图长什么样
3. 回到工作台，点右上角「导入数据」，选你的表格
4. 看表格上方的摘要：解析了多少行、匹配上多少、有多少行灰色
5. 右侧面板调配色和标题
6. 右上角「免费导出」，选 2x、透明背景，下载 PNG

第一次先用样例数据跑一遍，比直接上自己的表快很多。

---

## 1. 准备数据

### 最小可用结构

两列就够：左边地名，右边数值。表头可写可不写。

| 区域 | 数值 |
| --- | --- |
| 广东省 | 135673 |
| 江苏省 | 128222 |

### 地名怎么写

- **全称或简称都行。**「广东省」和「广东」、「北京市」和「北京」都能对上。
- **一行只写一个层级。** 「广东省深圳市」这种组合名对不上，写成「深圳市」即可；如果你的数据本来就是市级的，导入后选「全国-市」底图。
- **自治州可以写简称。** 克州、巴州、大理州这类常见简称已经内置。
- **别用没收录的俗称。** 比如「鹏城」「羊城」这种文学化的叫法，用正式行政区名。

### 数值要洗干净

这四种东西会让整列变成文本，颜色直接上不去：

| 写法 | 改成 |
| --- | --- |
| `135673 亿元` | `135673` |
| `12.5%` | `12.5` |
| `135,673` | `135673` |
| 空单元格、合并单元格 | 拆开，一格一个值 |

单位统一写进图表标题，比如「2025 年各省 GDP（亿元）」，图例里就不用每题都带单位。

### 多列指标

一张表里放好几列（人口、GDP、增速）完全可以。导入后在侧边栏切换「用哪一列上色」，不用为每个指标存一份表。

### 文件格式与限制

| 格式 | 说明 |
| --- | --- |
| `.xlsx` / `.xls` | 最常见，有多个工作表时会让你选导入哪一个 |
| `.csv` | 注意用 UTF-8 编码保存，避免中文乱码 |
| `.json` | 适合程序导出的数据 |
| 直接粘贴 | 从 Excel 选中两列复制，粘贴到文本框，Tab 分隔自动识别 |

单个文件不超过 **5MB**。几千行行政区数据远用不到这个上限。

## 2. 导入之后先看摘要

导入不会弹窗打断你，结果直接写在表格上方。它告诉你三件事：

- **解析了多少行** —— 文件真的读进来了，不是空文件
- **匹配上多少条** —— 这些会上色
- **未匹配多少条** —— 这些会是灰色，不上色

旁边还有一行「推荐地图」，会根据你的地名层级建议用哪一层底图（全国-省 / 全国-市 / 全国-区县，或某个省的市级图）。点一下推荐的名字就切过去了，不用自己猜。

**灰色行不是报错，是提示。** 它表示这些地名在当前底图里找不到。鼠标移上去、或直接在表格里把地名改成能对上的写法，颜色会立刻重新出现。

---

## 3. 调样式

右侧面板里能改的东西：

- **配色主题** —— 内置多套现成配色，赶时间就直接挑一套
- **起止颜色与色标** —— 分段还是连续、竖着还是横着、放在哪个角、要不要显示
- **背景色** —— 默认白色；深色主题会自动带深色底
- **主标题** —— 内容、字号、颜色、显不显示
- **地图标注** —— 显示区域名称或数值，可调字号、颜色、防重叠
- **标记点** —— 在地图上点一下就能打一个标记，适合门店、项目地址、重点区域
- **排行榜 / 柱状图** —— 和地图同屏，可放到四个角，说是「地图 + 排行榜」而不是两张图拼的
- **无障碍花纹** —— 开启后区域里会叠加纹理，色弱读者也能区分

原则很简单：**图上只留能回答问题的信息**。标题写「什么指标 + 什么年份 + 什么单位」，标注看情况开，不需要的就关掉。

## 4. 导出

导出面板里只有四个选项，但组合起来差别很大：

| 选项 | 怎么选 |
| --- | --- |
| 格式 | 要放进 PPT / 微信 / 文档：**PNG**；要放大印刷或再排版：**SVG** |
| 清晰度 | 屏幕上用 **1x**；放进 PPT、公众号、报告：**2x（推荐）**；印刷或大屏：**3x** |
| 背景 | 深色幻灯片上用**透明**；白底文档用**不透明** |
| 水印 | 默认保留审图号水印；需要干净图面时可选去水印 |

文件名默认取图表标题，导出前把标题改好，文件名也一并整齐了。

SVG 是矢量的，放大不会糊，适合再塞进设计稿或印刷。

---

## 5. 分享

点「分享」会得到：

- **一条短链接** —— 对方在手机或电脑浏览器打开，看到的就是同一张图，不用装任何东西，链接长期有效
- **一个二维码** —— 适合现场讲解、海报、群里发
- **一段嵌入代码** —— 贴进支持 HTML 的文档或博客，保留完整的缩放和下钻交互，可选 16:9 / 4:3 / 1:1 / 21:9 四种比例

如果数据量特别大导致链接过长，二维码会提示改用链接分享，这是正常的。

## 6. 卡住了？对照这张表

| 看到的症状 | 多半是 | 怎么做 |
| --- | --- | --- |
| 地图一片白，没有任何颜色 | 数值列被当成文本 | 去掉单位、百分号、千分位逗号 |
| 大部分行是灰色 | 地名带多级组合、错别字、未收录的俗称 | 一行只写一个层级的地名，改完自动重新上色 |
| 某个区县怎么改都不上色 | 它是经济功能区或已撤销的旧地名，本地图里没有边界 | 合并到所在行政区，或改成现名 |
| 数据里同时有省和市 | 层级混在一起 | 统一到同一层级，或利用逐级下钻分开看 |
| 图上信息找到了，但颜色不好看 | 主题不适合这个场景 | 换主题，或手动改起止颜色 |
| 导出的图有白边 | 背景选了不透明 | 改成透明背景 |
| 导出的图有点糊 | 清晰度选了 1x | 改成 2x 或 3x |
| 分享链接太长、二维码不出来 | 数据量太大 | 用链接分享，或精简数据后再生成 |
| 手机上很难编辑 | 屏幕太窄 | 制作建议在电脑上，手机只看分享页 |

## 7. 关于隐私与底图

- 数据解析、地图渲染、图片导出全部在浏览器本地完成，**不上传服务器**，工具没有后台数据库。
- 底图与行政区划边界取自天地图，审图号 **GS(2026)4921号**（2026 年 10 月版本）。该数据用于地图可视化展示；正式出版、公文报送或对外发布前，请以天地图当前公示的审图号与标准地图再核验一次。
